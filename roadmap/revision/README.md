# Revision Track

Short-form **active recall** after you study. Curriculum modules stay the textbook; **sample Q&A** is the guided teaching path; **revision** here is the timed drill twin.

## How to use

1. First learn (or re-learn) with guided cards: `../weeks/week-XX/day-YY/sample/`
2. Optionally deepen in full modules: `../weeks/week-XX/day-YY/` (`01`–`05`)
3. Close both
4. Open the matching file here: `weeks/week-XX/day-YY.md`
5. Speak flash prompts + timed drills cold — peek only for gaps
6. Weekly pack: [`flashcards/week-0N.md`](flashcards/week-01.md)

## Layout

```
revision/
  README.md
  weeks/week-XX/day-YY.md   ← compact refresh + drills (not a textbook)
  flashcards/week-0N.md     ← weekly front/back pack
```

## Shape of each day file

1. **Outcome** — what you must say aloud
2. **Concept refresh (simple)** — pin truths from that day’s sample (not full chapters)
3. **Read these** — sample first, then modules / story links
4. **Map to your work** — resume-true stories only
5. **Flash prompts** — cover answers, speak
6. **Timed drills** — budgets from the timing guide

## Rules

- Do **not** expand revision into textbooks — growth goes to full chapters or sample cards
- Metrics and company claims must stay resume-true (see `../provenance/`)
- Prefer everyday words; keep terms (MVVM, SDUI, ATS, …) with plain meaning
- Labels: **Verified** vs **How I would apply it** vs **Learning-lab** — never blur them
