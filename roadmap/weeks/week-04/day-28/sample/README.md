# Day 28 sample — guided Q&A

> Separate teaching sample. Does **not** replace the main Day 28 modules. 
> Use this when you want game-day taper as **question → module pointer → answer → follow-ups**.

## How to use

1. Read the question.
2. Follow **Points to** and skim that module section (optional first pass; answers stand alone).
3. Read the **Answer** in full.
4. Cover the follow-up answers and try to speak them, then check.

After the sample, run the taper protocol in [`../05-exercises.md`](../05-exercises.md) — then **stop**.
