## 2. Concept refresh (simple)

### 2.1 STAR rhythm (memorize the clock)

```text
20s  Situation / Task
90s  Action  (specific, you-owned)
30s  Result  (verified metrics only)
20s  Lesson  (what you’d repeat / avoid)
```

**STAR >4 min looks junior.** Open with a one-line headline; don’t bury the result.

### 2.2 Priority story set

| ID | Prompt fit | Verified metric |
|---|---|---|
| **BookMyShow LE Bottom Sheet** | Conflict, cross-team, product UI | **30%+** fewer full-screen navs on **targeted flows** |
| **BookMyShow IMOC + crash-free at scale** | Incident, reliability, scale | **30L+ DAU**, **99.95%+** crash-free |
| **District Free Parking + Clean/MVVM + AI tooling** | AI judgment, architecture, mentorship | Context engineering — not “AI wrote the app” |
| **BookMyShow Ads pipeline + HeroWidget lifecycle** | Revenue, POP, lifecycle | HeroWidget + type-safe pipeline — **no fill-rate %** |

### 2.3 Provenance walls

| Story | Allowed | Forbidden |

### 2.4 Critical truths (pin)

| Claim | Truth |
|---|---|
| STAR timing | 20s S/T → 90s Action → 30s Result → 20s Lesson |
| BookMyShow LE Bottom Sheet metric | **30%+** fewer full-screen navs on **targeted flows** — not all of BMS |

| BookMyShow Ads pipeline + HeroWidget lifecycle | No invented fill-rate or revenue % |
| STAR >4 min | Looks junior — clock discipline matters |
