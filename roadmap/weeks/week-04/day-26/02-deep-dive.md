# 02 — Deep Dive: Conflict, Incident, Mentorship, AI Judgment

---

## 1. Conflict script structure (S6 primary)

1. Disagreement named (API shape, scope, UX).
2. What you did: data, options, user impact, contracts.
3. Disagree *with* people, not *at* them.
4. Resolution + relationship intact.
5. Lesson: contracts and metrics over opinions.

**LE Bottom Sheet:** Align PM/Design/Backend; lighter overview; **30%+** flows fewer full-screen navigations.

---

## 2. Incident script structure (S8)

1. Severity + user impact at **30L+ DAU**.
2. IMOC role: stabilize → communicate → RCA → prevent.
3. Concrete technical/process action.
4. Result tied to **99.95%+ crash-free** culture.
5. Lesson: ownership + blast radius + rollback > hero debug.

---

## 3. Mentorship / leadership without title (S1 and friends)

> “Leadership was setting technical direction, unblocking others, and owning rollout checklists — not waiting for a manager title.”

S1: POP + generics standards on revenue module. S10/S14: SDK boundaries / zero-regression checklist.

---

## 4. AI tooling judgment (S9) — no tool-worship

**Wrong:** “AI writes my code; I’m 10×.”  
**Senior:**

1. Problem: migration / tests needed leverage without surrendering design.
2. Action: shaped **context** — modules, conventions, acceptance, review bar.
3. Judgment: rejected bad generations; human oracle on critical tests.
4. Separate product AI (S15/S16).
5. Lesson: tools amplify clear thinking; ownership stays yours at scale stakes.

**Timed opener:**  
> “At District I used AI as an accelerator for migration/tests — the skill was context engineering and review judgment, not prompting theater.”

## 5. Trade-offs

| Choice | When | Cost |
|---|---|---|
| Data-backed disagreement | Cross-functional conflict | Prep time |
| Escalate early | Safety/security/revenue | Political capital |
| AI-generated tests | Boilerplate | False green |
| Hand-written critical tests | Money, identity, crashes | Slower |
| STAR >4 min | Never | Looks junior |

## 6. Failure STAR — choose a real miss (do not invent)

Pick **one** you can defend:

| Candidate miss | Process change you can name |
|---|---|
| Pin rotation / break-glass under-specified | Document S4-A1 design; staged rollout thinking |
| SDUI unknown-type gap | Fallback + schemaVersion (S3-A1) |
| Race that escaped before sync maps | Concurrency boundary + tests (S2) |

**Script spine:** miss → impact → what you changed → how you detect recurrence.
